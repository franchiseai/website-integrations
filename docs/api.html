Download OpenAPI specification:

URL: https://github.com/franchiseai/website-integrations

← Integration guides · Download OpenAPI

The existing public HTTP surface used by @franchiseai/website-integrations. Prefer the package for React/Astro websites so validation, page saves and server progression remain consistent. These routes require no admin token or cookie. Application IDs are opaque credentials, not publicly shareable identifiers. CORS must permit the customer website origin. Response schemas describe the fields used by qualification and allow additional platform metadata. This document does not cover signing, booking or administrator endpoints. See the integration guides at https://franchiseai.github.io/website-integrations/.

Qualification

Capture and save qualification answers.

Start an enquiry or request secure continuation

For a new visitor, creates a lead and returns its opaque credential. For a returning email, returns resume_link_sent without a credential. That response is identical if delivery is suppressed, throttled or fails; it is not a delivery receipt. The integration reuses this endpoint for secure email continuation.
