# Prompt: brand website

Give this prompt to the agent that builds the brand's website. Replace `<Brand Name>` first.

```text
Build the website for <Brand Name> as a static site: plain HTML, CSS, JS and images, with no server code. A Next.js static export (out/) is fine.

- index.html must be at the top of the folder. Each page is a folder with its own index.html, for example about/index.html.
- File names use only letters, digits, ".", "-" and "_".
- Zip the folder and give me the ZIP.
```

## Upload

1. Go to Admin, Sites, the brand's card, **Site Preview**.
2. Drop the ZIP.
3. Click **Show To Brand**. The brand sees only the version you show.
