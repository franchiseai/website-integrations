# Agency integration guide

For website integration work read site/getting-started.md and site/contract.md, then site/development.md or site/going-live.md. The documentation is the contract. Use demo data until a live configuration is supplied. The live Funnel API specification is openapi.json. For Portal brands read site/portal.md: the repository-only prototype and portal-openapi.draft.json are experimental, not available in npm 0.1.0 or deployed as a live integration. This repository is a curated distribution; see site/maintaining.md before changing release files.
